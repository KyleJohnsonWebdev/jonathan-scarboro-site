# maletherapistinportland.com: temporary site

Static HTML on Bootstrap 5.3.8, generated by `build.py`. It stands in until the Astro/Sanity build is ready.

**Domains:** `maletherapistinportland.com` is the main one. `jscar.care` (printed on the zines) and `therapyformenportland.com` 301-redirect to it. Email stays `hi@jscar.care`.

## Layout of this repo

- `docs/` is the website, and the only folder that gets published. Everything in it is public.
- `build.py` regenerates every page in `docs/` (shared header, footer, structured data, sitemap, `_redirects`, `_headers`). Run `python3 build.py` after editing it. It needs Pillow (`pip install pillow`) to read image sizes.
- `README.md` (this file) is not published.

Never put notes, drafts or internal documents in `docs/`.

## Deploy

- **Cloudflare Pages:** framework preset none, build command none, **build output directory `docs`**. Deploys from the private GitHub repo.
- **GitHub Pages (preview):** Settings → Pages → deploy from branch `main`, folder **`/docs`**.
- `docs/_redirects`: 301s for the old mmm.page paths (`/about`, `/main` → `/`; `/approach`, `/dudes` → `/help/`; `/blocks` → `/zine/`; `/business` → `/fees/`), with and without a trailing slash.
- `docs/_headers`: CSP (self only), nosniff, referrer policy, permissions policy, frame blocking; `X-Robots-Tag: noindex` on the zine PDF; 7-day caching for `/assets/`.
- Links are relative and point at `index.html`, so the site works from disk, on a `github.io/<repo>/` URL and at a domain root. The 404 page uses root-absolute paths.
- **Local preview:** `python3 -m http.server -d docs`, or `npx wrangler pages dev docs` to test redirects and headers as Cloudflare serves them. Fonts don't load from `file://`.

## Design system

- **Type:** Bricolage Grotesque (titles, section headings, closing lines, site name) and Familjen Grotesk (everything else). Both self-hosted variable fonts (SIL OFL) in `docs/assets/fonts/`. Arial fallbacks are size-matched so text doesn't jump while fonts load.
- **Colour:** white page, ink text. Colour comes from the photos: each photo page's main buttons use that photo's colour with black text; the three step circles on Contact use all three, in menu order (`page(..., theme="coral" | "turquoise" | "lime")`). Contrast with black text: coral 6.8:1, turquoise 12.6:1, lime 13.3:1. Buttons elsewhere are black.
- **Sections:** Home, What I help with, Fees + FAQ and Contact are stacked sections (`.sections` / `.sec` in `site.css`). Below 992px the large cutout is replaced by a 104px circle crop (`*-avatar.jpg/.webp`, art-directed with `<picture>`).
- **States:** buttons lighten on hover and deepen when pressed; text links thicken their underline; keyboard focus is a 3px ink outline everywhere. Motion is off for reduced-motion users.
- **JavaScript:** Bootstrap's bundle (the phone menu) and `assets/js/site.js` (opens the Good Faith Estimate details from its link). The site works without either.

## Content switches in build.py

- `ACCEPTING_NEW_CLIENTS`: set to `False` to remove every "Currently accepting new clients" line.
- `FAQ`: the questions on Fees + FAQ. The page and its FAQPage markup both come from this list, so they always match.

## SEO

- Unique titles (60 characters or fewer) and descriptions (160 or fewer), canonical URLs, link-preview tags, one H1 per page.
- Home structured data: `WebSite`, `Person` (LPC license C8085, OBLPCT; `sameAs` Psychology Today) and `MedicalBusiness` (1210 SE Oak St, Portland, OR 97214). Fees: `FAQPage`.
- `sitemap.xml` with lastmod dates. `robots.txt` lets every crawler read every page; named AI training crawlers are kept off the zine PDF, which also carries `noindex`.
- Keep the footer's name, address and email identical to Psychology Today and other listings.
